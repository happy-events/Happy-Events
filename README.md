## 🚀 How to Host on GitHub Pages (આ સાઇટ GitHub પર કેવી રીતે હોસ્ટ કરવી):

આ સાઇટ પ્યોર સ્ટેટિક HTML/CSS/JavaScript માં બનેલી છે, એટલે કોઈપણ બિલ્ડ સ્ટેપ વગર ડાયરેક્ટ GitHub Pages પર મફતમાં લાઈવ થઈ જશે.

### સ્ટેપ ૧: GitHub પર નવું રિપોઝીટરી બનાવો
1. [github.com](https://github.com) પર જાઓ અને લૉગિન કરો.
2. `New repository` પર ક્લિક કરો.
3. રિપોઝીટરીનું નામ આપો, ઉદાહરણ તરીકે: `Happy-Events` (અથવા `happy-events`).
4. તેને `Public` રાખો અને `Create repository` પર ક્લિક કરો.

### સ્ટેપ ૨: આ ફોલ્ડરની ફાઇલો Git માં કમિટ અને પુશ કરો
તમારા કમ્પ્યુટરમાં કમાન્ડ પ્રોમ્પ્ટ અથવા પાવરશેલ ખોલી નીચેના કમાન્ડ ચલાવો:
```bash
cd e:\Happy-Events
git init
git add .
git commit -m "Launch Happy Events 19 Services Website with Full Animations"
git branch -M main
git remote add origin https://github.com/<તમારું-યુઝરનેમ>/Happy-Events.git
git push -u origin main
```

*(નોંધ: `<તમારું-યુઝરનેમ>` ની જગ્યાએ તમારું GitHub એકાઉન્ટ નામ લખો).*

### સ્ટેપ ૩: GitHub Pages એક્ટિવેટ કરો
1. GitHub પર તમારી `Happy-Events` રિપોઝીટરી ખોલો.
2. ઉપર આપેલા **Settings** ટેબ પર ક્લિક કરો.
3. ડાબી બાજુ મેનુમાંથી **Pages** સિલેક્ટ કરો.
4. **Build and deployment** સેક્શનમાં:
   - **Source**: `Deploy from a branch` પસંદ કરો.
   - **Branch**: `main` અને ફોલ્ડર `/ (root)` પસંદ કરીને **Save** પર ક્લિક કરો.
5. ૧ થી ૨ મિનિટમાં તમારી સાઇટ લાઈવ થઈ જશે!
   - તમારી લાઈવ સાઈટની લિંક આવી હશે:  
     `https://<તમારું-યુઝરનેમ>.github.io/Happy-Events/`
